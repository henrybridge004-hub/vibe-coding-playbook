# Vibe Coding 能力场景库

一份把技术名词翻译成“能做什么、什么时候想到它、怎么用、还能迁移到哪里”的交互式能力地图。

## 包含什么

- 60 个技术能力，按 L1–L6 难度分层
- 每个能力 1 个最小案例 + 3 个迁移场景，共 180 个场景
- 182 个专业术语的随点随查解释
- 3 个组合项目：AI 招聘助手插件、招聘自动化系统、浏览器增强工具箱
- 中文别名搜索、能力进度记录、官方资料链接

直接打开 `index.html`。页面是单文件自包含实现，不依赖本地服务。
